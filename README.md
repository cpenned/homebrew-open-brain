# Open Brain for Mac

Homebrew tap for the Open Brain Mac app (macOS 26+).

```sh
brew install --cask cpenned/open-brain/open-brain
```

## Updating

The app checks this repo every six hours and posts a notification when a new
version is out (also Open Brain > Check for Updates…). Then:

```sh
brew upgrade --cask open-brain
```

Releases: https://github.com/cpenned/homebrew-open-brain/releases
